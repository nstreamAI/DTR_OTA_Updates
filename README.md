OTA updates repo for the All Aboard! train station departure board.

A custom train departure board project built on an ESP32-S3 Matrix Portal, 3x P2.5 LED Matrix displays and custom 3d printed housing.

Featuring:
- National Rails Darwin API
- Product onboarding through BLE and authentication through code activation
- Screensavers
- Weather API
- 100 percent on device station selection and UI
- Automatic light dimming
+ many other features.

Designed and developed by David Newton - 2026.
